## The entry

> I took you through the cemetery because the traffic was dead and frankly so was my signal.

90 characters, one line. The GPS defends its detour through a cemetery with a dead-traffic pun, then lands the second twist: its own signal was dead too — smug, defensive, and blaming its own tech while pretending it was a plan.

## Run

```sh
node main.ts
```

Writes the entry to `entry.txt` inside `MAKEFUN_OUTPUT_DIR` (or `./out` when unset). Deterministic, no network, no dependencies.
